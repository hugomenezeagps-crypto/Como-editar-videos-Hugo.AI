# Como editar vídeos com o Claude — Hugo.ia

Método para o Claude Code editar seus vídeos: corte, áudio, legenda palavra por palavra e animação sob medida no Remotion.

## Como começar

1. Crie uma pasta no seu PC e abra o Claude Code nela.
2. Cole este prompt:

```
Clone o repositório https://github.com/hugomenezeagps-crypto/Como-editar-videos-Hugo.AI dentro desta pasta.

Depois, prepare tudo para eu editar vídeos com ele:
1. Leia o CLAUDE.md do repositório.
2. Confira se Node, FFmpeg e Python estão instalados no meu PC. Instale o que faltar.
3. Instale o faster-whisper no Python e já baixe o modelo "medium".
4. Rode o npm install dentro da pasta modelo-remotion.
5. No final, me mostre a lista do que foi instalado e confirme que está tudo pronto.

Antes de instalar qualquer coisa, me diga o que vai instalar.
```

3. Abra o Claude Code dentro da pasta `Como-editar-videos-Hugo.AI` e diga: **"tenho um vídeo novo para editar"**.
